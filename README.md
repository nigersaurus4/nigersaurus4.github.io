# yuan-chengzhi.github.io

Personal research atlas for Chengzhi Yuan / 袁诚志.

The site is intentionally data-driven: add a project card in `data/projects.json`, update the relation list in `data/research-map.json`, and revise the static map when a new branch becomes meaningful. The public site separates collaborative work, personal contribution, evidence, and working directions.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
